# Snow Crash

**Snow Crash** is one of the first major cybersecurity projects in the advanced **42** curriculum. It introduces a wide range of security concepts through hands-on exploitation challenges, encouraging participants to think like both attackers and defenders.

Throughout the project, you will discover and exploit vulnerabilities across multiple domains of computer security. Along the way, you will gain practical experience with several programming and scripting languages, including **Assembly**, **C**, **Perl**, **PHP**, and **Lua**, while learning how common implementation mistakes can lead to privilege escalation.

## Project Structure

The project consists of **10 mandatory levels** and **5 bonus levels**. Each level presents a unique challenge that requires identifying and exploiting a specific vulnerability or security misconfiguration.

The central objective of **Snow Crash** is **user privilege escalation**. For every level, your goal is to obtain the privileges of the corresponding `flagXX` user. Once you have successfully escalated your privileges, you can retrieve the password for the next level by running:

```bash
$ getflag
Check flag.Here is your token : XXXXXXXXXXXXXXXXXXXX
```

The generated token serves as the password for the next level, allowing you to progress through the project until all challenges have been completed.
